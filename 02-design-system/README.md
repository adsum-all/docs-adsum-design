# 02 · Design System - ADSUM

Dossier réservé à la **phase Design System** (à construire après validation des wireframes).

Contiendra le système complet attendu d'un projet d'entreprise :
- **Couleurs** - palette (base bleue pour le pilote), neutres, sémantiques (succès, alerte, info), modes clair/sombre.
- **Typographie** - échelle, graisses, styles (le style d'écriture actuel reste par défaut).
- **Espacements & rayons** - grille, radii, ombres.
- **Composants** - boutons, champs, cartes, badges, tableaux, navigation (rail repliable), barres d'onglets, modales, états.
- **États & motifs** - chargement, vide, erreur, hors-ligne, accès refusé.
- **Marque** - logo, iconographie.

Point d'entrée prévu : `index.html` (ou `Design System.dc.html`).
